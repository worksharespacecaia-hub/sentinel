## 事件摘要
NHN Dooray 公告攻擊者利用忘記密碼流程反覆嘗試驗證碼並變更帳號密碼，另 Open API 服務漏洞導致部分 API 金鑰外洩。部分客戶的業務資料與員工個資外洩，業者已撤銷所有 API 金鑰並通報主管機關。

## 不受影響與需確認
- 需確認：*：人工判斷事件的攻擊手法是否適用於我們的系統；把事件對應到 controls.yaml 的控制項；沒有合適的就建議新增；建議新增控制項：忘記密碼流程的驗證碼須限制嘗試次數
  - （推測）員工帳號密碼被釣魚，攻擊者用它登入內部系統；查：確認內部工具與管理介面都啟用雙因素驗證，檢查近期的異常登入；系統：內部營運工具、辦公室 NAS、資料庫網頁管理工具
  - （推測）伺服器的遠端管理帳密被猜中或外洩；查：確認遠端管理只允許公司網路或 VPN 連線，並停用純密碼登入或啟用雙因素驗證；系統：辦公室 NAS
  - （推測）資料庫帳密或連線字串外洩（放在程式碼、設定檔或員工電腦上）；查：確認資料庫帳密沒有放在程式碼或設定檔中，疑似外洩時立即輪替；系統：正式訂單資料庫帳密、測試訂單資料庫帳密
  - （推測）員工電腦中毒，電腦上存的登入權杖或金鑰被拿走；查：確認員工電腦上沒有長期有效的部署或雲端權杖，並檢查端點防護告警；系統：辦公室檔案伺服器、工程部門筆電（甲）、工程部門筆電（乙）、維運部門筆電、辦公室 NAS
